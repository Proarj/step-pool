# StepPool

A private step challenge for one group of friends. Everyone picks their own
daily stake in virtual coins, and whoever misses the group's step goal pays
their stake to the people who hit it, split by how much each winner staked.
Design:
`docs/superpowers/specs/2026-10-10-steppool-design.md`.

## Requirements

- Node 24 (`nvm use` picks it up from `.nvmrc`)

## Tests

```bash
nvm use
npm test          # SQL tests run the real migrations in PGlite: no Docker, no accounts
npm run typecheck
```

## Database

All backend logic is in `supabase/migrations/`:

| File | What it does |
|---|---|
| `…01_schema.sql` | Tables, IST clock helpers, sign-up trigger, write lockdown (the 1,000-coin wallet it created was removed by `20261011000001`) |
| `…02_groups.sql` | `create_group`, `join_group`, `update_group_settings` (from tomorrow), `leave_group` |
| `…03_steps.sql` | `upload_steps`: only for today in IST |
| `…04_scoring.sql` | `score_pending_days`: settles every unscored day before today |
| `…05_read_access.sql` | Row Level Security: members see their group and its people only |
| `…06_cron.sql` | Runs scoring every hour on the hour IST (Supabase only) |
| `20261011000001_stakes.sql` | Rules update: per-person stakes (`set_my_stake`), losers pay winners in proportion to the winners' stakes (`day_transfers`), no wallet (`group_totals` can go negative). Wipes all game data |
| `20261011000002_leave_now.sql` | Leaving takes effect immediately (you sit out that day). Wipes all game data again |

**Rules in one paragraph:** everyone in a group shares one daily step goal and
picks their own stake (1–1,000 coins). At 12:00 AM IST, each person who missed
the goal pays each person who hit it `floor(loser stake × winner stake / total
winners' stake)`, and rounding stays with the loser. If everyone or nobody hit
the goal, nothing moves. Totals start at 0. Changes to the goal or a stake take
effect the next day. Leaving takes effect immediately.

Apply them to a Supabase project:

```bash
npx supabase login
npx supabase link --project-ref <your-project-ref>
npx supabase db push
```

## The app

An Expo SDK 57 app in `src/`, with expo-router screens in `src/app`. It talks
to the Supabase project set in `.env`. That file is committed on purpose: both
values are public by design, and the secret key is never in this repo. The
native folders `ios/` and `android/` are generated by `npx expo prebuild` and
are not committed.

### Android (APK, no store, no account)

```bash
nvm use
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
npx expo prebuild --platform android --clean
(cd android && ./gradlew assembleRelease)
# → android/app/build/outputs/apk/release/app-release.apk
```

Send the APK by Google Drive, WhatsApp or similar. On the phone, open it and
allow "Install unknown apps" when asked. Then, in StepPool, tap **Set up step
access**.

## Installing StepPool on your iPhone (for friends)

There's no App Store version, so you build the app on your own Mac with your
free Apple ID and install it straight onto your iPhone. Budget about an hour
the first time, most of it waiting for Xcode to download. After that it takes
a minute.

**You need:**
- a Mac with a recent macOS and about 40 GB free
- your iPhone and its cable
- a free Apple ID
- the Google account you'll sign in with. Send its address to the group
  organiser first; until they add you as a tester, Google sign-in is blocked.

### 1. Install Xcode (one time)

1. Open the **App Store** on your Mac, search for **Xcode** and click **Get**.
   It's a large download, so leave it running.
2. Open Xcode once. Accept the licence, and if it asks which platforms to
   install, tick **iOS**. You can also add it later under **Xcode → Settings →
   Components**.
3. Add your Apple ID under **Xcode → Settings → Accounts → + → Apple ID**. This
   creates your free "Personal Team" for signing apps.
4. Open **Terminal** and run:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -license accept
   ```

### 2. Install the tools (one time)

In Terminal:

```bash
# Homebrew (skip if you have it), then Node.js 24, CocoaPods and git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node@24 cocoapods git
echo 'export PATH="$(brew --prefix node@24)/bin:$PATH"' >> ~/.zprofile && source ~/.zprofile
node -v   # should print v24.x
```

### 3. Get the code (one time)

```bash
git clone https://github.com/Proarj/step-pool.git
cd step-pool
npm ci
```

The repo is public, so you don't need a GitHub account to download it.

### 4. Prepare your iPhone (one time)

1. Plug the iPhone into the Mac, unlock it, and tap **Trust** when asked.
2. Turn on **Developer Mode**: **Settings → Privacy & Security → Developer
   Mode → On**. The iPhone restarts. If you don't see the option, open Xcode
   with the phone plugged in, then check again.

### 5. Build and install

Pick a bundle id that's unique to you, such as `com.yourname.steppool`, and
always use the same one. Then run:

```bash
cd step-pool
IOS_BUNDLE_ID=com.yourname.steppool npx expo prebuild --platform ios --clean
open ios/StepPool.xcworkspace
```

In Xcode, click **StepPool** at the top of the left sidebar, open the **Signing
& Capabilities** tab, and set **Team** to *Your Name (Personal Team)*. Leave
the rest as it is. Then, back in Terminal:

```bash
IOS_BUNDLE_ID=com.yourname.steppool npx expo run:ios --device --configuration Release
```

Choose your iPhone when asked. The first build takes several minutes.

### 6. First launch

1. If the iPhone says **"Untrusted Developer"**, go to **Settings → General →
   VPN & Device Management**, tap your Apple ID, and choose **Trust**.
2. Open StepPool and tap **Continue with Google**. If iOS asks to use
   "supabase.co" to sign in, tap **Continue**. If Google says the app isn't
   verified, tap **Continue** there too.
3. Tap **Set up step access** and allow **Steps**. Then **Join with a code**,
   enter the invite code, and choose your stake.

### Every 7 days

Apps signed with a free Apple ID stop opening after 7 days. StepPool reminds
you on day 6. Plug the phone in and run only this from the `step-pool` folder:

```bash
IOS_BUNDLE_ID=com.yourname.steppool npx expo run:ios --device --configuration Release
```

Your data is kept, because everything lives on the server. To get the latest
version first, run `git pull && npm ci`.

### If something goes wrong

| Problem | Fix |
|---|---|
| "No profiles for 'com.…' were found" / signing errors | Set **Team** in Xcode (step 5). If the bundle id is taken, pick another and use it every time |
| "Developer Mode disabled" | Step 4.2, then restart the iPhone |
| `pod: command not found` | `brew install cocoapods` |
| Google says access is blocked | The organiser hasn't added your Google address as a tester yet |
| Your steps stay at 0 | Health app → your profile picture → Apps → StepPool → turn on **Steps** |
| "Maximum number of apps" | Free Apple IDs can sideload 3 apps per device; delete one you built earlier |

### After a fresh `supabase db push`

In the Supabase SQL editor,
`select jobname, schedule, active from cron.job;` should show
`score-pending-days | 30 * * * * | true`.
In Authentication → Sign In / Providers, keep only **Google** enabled.
